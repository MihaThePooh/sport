# Дневник тренировок

Запись подходов в три движения, барабанный выбор даты и выгрузка в
Excel. Ставится на телефон как приложение (PWA).

Зависимостей нет, кроме `openpyxl` — и тот нужен только для выгрузки
в `.xlsx`. Сервер и интерфейс обходятся стандартной библиотекой.

## Запуск

```
python3 server.py
```

Откроется на `http://127.0.0.1:8790`. Порт задан в `server.py`.

При первом запуске рядом появится папка `data/` — пустая, записи
начнутся с первой сохранённой тренировки.

## Доступ

Ни логина, ни пароля. Дневник открывается ключом — 64 шестнадцатеричных
знака, 256 бит случайности. Браузер заводит его сам при первом заходе,
хранит у себя и присылает заголовком `Authorization: Bearer`.

Проверять ключ не с чем и не надо: **любой ключ нужной формы открывает
свой собственный дневник**. Отсюда многопользовательность бесплатно —
дал ключ другому, у него свой дневник, а не твой. Угадать чужой — это
перебрать 2^256 вариантов.

Перенести дневник в другой браузер или на другой адрес — открыть его
один раз со ссылкой вида:

```
https://адрес/#k=КЛЮЧ
```

Страница заберёт ключ и сама вычистит его из адресной строки, чтобы он
не остался в истории браузера.

Ключ хозяина лежит в `data/token` и создаётся при первом запуске. Его
записи хранятся прямо в `data/`, чужие — в `data/lists/<хеш ключа>/`.
Имя папки — хеш, поэтому список папок не выдаёт ни одного ключа.

Страница, иконки и манифест открыты без ключа: иначе неоткуда было бы
взяться браузеру, который его предъявит. Всё под `/api/` — только с
ключом.

## Хранение

Источник правды — обычный CSV, одна строка на упражнение за день:

```
дата,упражнение,подходы,всего,формат,комментарий
2026-01-15,подтягивания,10 8 6,24,,
2026-09-13,подтягивания,9 3 3 3 \ 5 2 2 2,29,мио,мио-серии
```

Колонка «формат» пустая у обычных тренировок и равна `мио` у мио-серий.
Старые записи её не имеют вовсе — и это нормально: пусто читается как
обычная тренировка, переносить ничего не нужно. То же с «комментарием».

**Серии в одной ячейке.** Обратный слеш делит подходы на заходы: до
него первая серия, после — вторая. Две мио-серии подтягиваний за день
это одно занятие, а не два, и ключ записи остаётся прежним — дата плюс
движение. Запись без слеша читается как одна серия, поэтому четыре года
старых данных не потребовали ни строчки миграции.

Почему не сразу Excel: сервер, который переписывает книгу на каждое
нажатие, рано или поздно её испортит — формулы, стили, объединённые
ячейки. CSV портить нечем.

Красивая таблица собирается отдельно, из CSV, целиком заново:

```
python3 export.py
```

Она же пересобирается сама после каждой записи, так что
`data/тренировки.xlsx` всегда лежит рядом в актуальном виде.

Перенести старый дневник из Excel:

```
python3 import_xlsx.py книга.xlsx
```

Обоим скриптам нужен тот Python, под которым стоит `openpyxl`; если
он не основной, зови его прямо — например `python3.12 export.py`.

## Как устроена форма

Все три движения на одной странице, в каждой карточке три кнопки:

```
комментарий          открывает поле с тем,
                     что уже написано за день —
                     дописать, а не начать заново

записать серию       кладёт подходы серией рядом
                     с уже записанными,
                     помечает занятие как мио,
                     чистит поля до трёх и ждёт
                     следующего захода

записать тренировку  то же самое, но без пометки
                     и без подготовки к следующей серии
```

Обе кнопки записи ДОПИСЫВАЮТ. Заменяет день целиком только правка —
тап по строке таблицы внизу страницы.

В мио-серии первое число это активационный подход, остальные — круги;
сервер отказывает, если чисел меньше двух. Разбор самого метода лежит
в меню приложения, в разделе «Как тренироваться».

Комментарии пишутся к упражнению, а в книге собираются в одну ячейку
дня с именем движения впереди:

```
подтягивания: мио-серии \ отжимания: плечо ныло
```

## Проверки

```
python3 test_server.py
  формат записи и разбор
  старого CSV, 33 проверки

node ~/tools/uitest/sportui.js
  форма в браузере: серии,
  комментарий, таблица,
  правка — 30 проверок
```

Рядом лежат и остальные прогоны: `sport.js`, `sportdate.js`,
`sportsets.js`, `sportmove.js`, `sportkey.js`, `sporthead.js`.

Обе пишут во временные папки — боевой дневник не трогают.

```
                одним файлом
```

дело личное, а ключ и подавно.
